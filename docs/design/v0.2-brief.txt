1. PROBLEM
----------

The current UI says "AI experiment." It doesn't say "research tool."

  Symptom                          Why it fails
  -------------------------------  ----------------------------------------
  Emoji in navigation              Consumer app, not scholarly instrument
  3D galaxy as homepage            Impressive for 5s, unusable for real work
  Glowing spheres, nebula colors   Reads as "sci-fi demo," not "archive"
  Purple/blue gradients            Every AI startup since 2023 looks like this
  Rounded pills, floating panels   No reference to real scholarly tools
  No information density           One thesis per screen is wasteful
  No keyboard flow                 Scholars work at typing speed, not mouse
  No metadata sidebar              arXiv, Scholar, ChemRxiv all use one
  No sort, no filter, no cite      These aren't features, they're baseline
  Dark-only aesthetic              Half of academia reads in light, in daylight

The current UI is not bad. It's the wrong genre. It's a landing page
pretending to be an archive.


2. WHAT SANKOFA IS
------------------

Before designing the interface, we name what Sankofa is - because the UI
must be the shape of its purpose.

  Sankofa is:
    - A thesis archive for AIMS students and supervisors
    - A place scholars go to find, read, cite, and question theses
    - A knowledge graph that connects ideas across cohorts and campuses
    - A quiet intelligence that reads the archive and proposes what's missing

  Sankofa is not:
    - A chatbot
    - A 3D experience
    - A showcase for AI
    - A productivity dashboard

  The user's mental model:
    "I'm a PhD student. I need to find every AIMS thesis on stochastic
     epidemics since 2018. I'll read three abstracts, download one PDF,
     cite it in my lit review. Tomorrow I'll ask the archive what's
     missing in this space."

Every design decision must serve that person.


3. REFERENCES
-------------

We borrow from three tools, each for a specific reason.

  arXiv.org - for density
    Everything is text. IDs are monospace. Abstracts are one paragraph,
    always visible. No images, no cards, no decoration.
    Steal: the list view, the typography, the restraint.

  Google Scholar - for flow
    One search box. Results: title (blue link) - authors - journal - year
    - snippet. Sidebar: "Cited by", "Related articles". Sort by relevance
    or date.
    Steal: the metadata hierarchy, the search-first homepage.

  ChemRxiv - for structure
    Category tags, cleanly displayed. Download buttons prominent but not
    loud. Author affiliations listed plainly.
    Steal: the category system, the license/consent display.

  What we do NOT steal: ads, tracking, clutter, pagination. Sankofa is
  smaller, faster, kinder.


4. PRINCIPLES
-------------

Seven rules to be held to.

  1. Text is the interface
     No decorative graphics on primary screens. A thesis is a title, an
     abstract, metadata. The interface is typography. Images appear only
     where they add information - a small graph preview in the sidebar,
     never a hero image.

  2. Density over whitespace
     Aim for 8-12 theses visible on a laptop screen, not 2. Whitespace is
     for separation, not decoration.

  3. Search is the entrance
     The homepage is a search box. Not a hero, not a carousel, not an
     intro animation. A single input, a single button, a list of recent
     theses below.

  4. Metadata is content
     A thesis is author, campus, year, concepts, citations, reads,
     license, consent. All visible on the detail page, in a fixed sidebar.
     Never hidden behind "show more."

  5. Keyboard-first
       /        focus search
       j / k    next/previous thesis
       Enter    open focused thesis
       g h      go home
       g g      go to graph
       Esc      clear search / close modal
     No mouse required.

  6. One accent, one mode
     Light mode by default. Dark mode toggle. Single accent color (blue
     for links). No gradients. No glow. No shadow.

  7. Graph is a destination, not a home
     The 3D constellation exists at /graph. It's a view, not a place.

    animates.


7. INNOVATION
-------------

Innovation is in capabilities, not decoration.

  1. Search that understands concepts
     Hybrid: vector embeddings + graph reachability. Type "malaria" ->
     theses about it, theses citing it, theses using similar methods.
     Surface: one input.

  2. Every thesis speaks
     Chat is inline on the detail page. You don't go to a "chat page."
     You ask the thesis right there, in the flow of reading. arXiv
     doesn't have this. Scholar doesn't have it.

  3. The Oracle proposes what doesn't exist
     Google Scholar shows what's been written. Sankofa shows what
     hasn't. That's genuinely novel - and it deserves a clean page,
     not a chat bubble.

  4. The graph as a navigation tool
     Move from thesis to thesis through ideas - click a concept, see
     what else touches it. Reachable at /graph, not forced.

  5. Metadata as first-class content
     Consent status, license, tags, citations, reads - all visible.
     Most archives hide this. Sankofa shows it because Sankofa cares
     about sovereignty. The design says: this thesis is a person's
     work, and we honor that.


8. REMOVE / KEEP
----------------

  REMOVE
    - All UI emoji (logo, nav, buttons, headers)
    - The 3D galaxy from the homepage (moved to /graph)
    - Every gradient, shadow, glow
    - Rounded pills over 4px radius
    - Words: "AI", "magic", "intelligent", "powered by"
    - Colors: purple, teal, pink (only blue + gray)
    - The page name "Constellation" (becomes "Graph")
    - Animations over 120ms
    - Any marketing-toned copy

  KEEP
    - Every backend capability (src/sankofa/ untouched)
    - API on port 8001
    - REPL (sankofa chat)
    - sankofa CLI
    - Three-interface model (CLI, REPL, API) + web UI as fourth
    - Name Sankofa, its meaning, ethics charter, offline-first
      philosophy

10. SUCCESS CRITERIA
--------------------

  The redesign works if:

    - A supervisor familiar with arXiv or Scholar feels immediately
      at home
    - A stranger can search, filter, open, and read a thesis in under
      10 seconds
    - Chat feels like a feature of reading, not a chat app bolted on
    - Page loads in under 300ms on a laptop
    - Nothing on screen says "AI"
    - The interface is fully usable without a mouse
    - A screenshot could sit next to arXiv and not look out of place


11. ONE-SENTENCE BRIEF
----------------------

  Redesign Sankofa as a scholar-grade archive: text-first,
  keyboard-native, dense, quiet, and serious - borrowing arXiv's
  restraint, Scholar's flow, and ChemRxiv's structure - while keeping
  every capability intact and moving the 3D graph from centerpiece to
  destination.


12. RECOMMENDED DECISIONS
-------------------------

  Decision          Recommendation
  ----------------  ------------------------------------------------
  Default view      List (arXiv-style). Graph at /graph.
  Emoji in UI       None. Not even in the logo.
  Color             Light mode default, blue accent, 4px radius,
                    120ms transition.
  Typography        Serif titles - sans body - mono IDs.
  Innovation        In hybrid search, inline chat, the Oracle, the
                    graph - not in decoration.
